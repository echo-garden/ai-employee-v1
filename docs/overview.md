# Overview

AI Employee v1 is a practical workspace structure for AI-driven development.

The idea is simple:

1. Put all project context inside the project folder.
2. Let AI agents read that context before working.
3. Manage tasks with Markdown files.
4. Record every completed task in a work log.
5. Use Git as a safety net.

This allows the user to avoid repeating the same explanation every time and makes development easier to manage from a PC or smartphone.
